NEON HARBOR is an original open-world crime game set in a fictional neon coastal city: explore on foot or by car, steal parked cars, dodge traffic and pedestrians, build a wanted level with police foot patrols, cruisers and a police helicopter, run six chained story missions, collect cash, tune the radio, and save your progress — all offline in a desktop browser.

## Run it

```sh
python3 -m http.server 8080 --directory game
```

Then open http://localhost:8080 in desktop Chrome. No build step, no network requests: every script, style and library is a file under `game/`.
